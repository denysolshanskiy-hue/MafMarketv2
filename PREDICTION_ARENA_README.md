# KMC Prediction Arena

KMC Prediction Arena додає до MafMarket систему прогнозів для 10 ігор фіналу сезону.

## Функціональність

- Прогнози: команда-переможець, перший убитий гравець, перший вигнаний гравець, «Найкращий хід».
- Нагороди: 50 МК за кожен із трьох звичайних правильних прогнозів; «Найкращий хід» — 100/60/20/0 МК за 3/2/1/0 збігів.
- Організатор відкриває/закриває категорії вручну, задає таймер та підтверджує правильні відповіді.
- Дані прогнозів і результати записуються в аркуш \`Ставки🎯\`; службовий стан — в аркуш \`СтавкиСтан\`.
- Винагороди ніколи не списуються за неправильні відповіді.
- Нагороди записуються в той самий рядок прогнозу лише один раз; загальний баланс має підсумовувати стовпець H аркуша \`Ставки🎯\`.

## Змінні оточення

Збережіть на хостингу чинні налаштування MafMarket (токен Telegram та облікові дані Google Sheets). Додатково:

- \`ADMIN_TELEGRAM_ID\` — Telegram ID адміністратора (також збережено сумісність з наявним ID 444726017).
- \`PREDICTIONS_WEBAPP_URL\` — повна HTTPS URL-адреса Mini App, наприклад \`https://your-public-host.example/predictions\`.
- \`PUBLIC_BASE_URL\` — необов'язкова базова HTTPS-адреса; якщо \`PREDICTIONS_WEBAPP_URL\` порожня, бот додає \`/predictions\`.
- \`PREDICTIONS_CHAT_ID\` — необов'язковий ID групового чату для повідомлень про відкриття прогнозу й результати.

Telegram Mini App вимагає HTTPS. Налаштуйте домен хостингу та задайте \`PREDICTIONS_WEBAPP_URL\` у змінних оточення Koyeb/іншого хостингу.

## Запуск

1. Розгорніть гілку \`feature/kmc-prediction-arena\` як тестову версію (не замінюйте production, доки не завершено перевірки).
2. Переконайтеся, що службовий Google-акаунт має доступ редактора до таблиці MafMarket.
3. Відкрийте бота і натисніть «🏆 Прогнози KMC».
4. У Mini App адміністратор відкриває категорію, вказує правильну відповідь і підтверджує розрахунок.

Під час першого звернення модуль перевіряє наявність аркушів \`Ставки🎯\` і \`СтавкиСтан\`, створюючи відсутні аркуші та заголовки. Якщо аркуш ставок уже існує, назви колонок A, B та H зберігаються.

## API

- \`GET /predictions\` — Mini App.
- \`GET /api/predictions/state\` — стан гри, власні прогнози, рейтинг.
- \`POST /api/predictions/submit\` — подання прогнозу.
- \`POST /api/predictions/admin/open\` — відкрити категорію.
- \`POST /api/predictions/admin/close\` — закрити категорію.
- \`POST /api/predictions/admin/settle\` — підтвердити правильну відповідь і розрахувати нагороди.

API перевіряє підпис Telegram Mini App \`initData\`. Адміністративні маршрути додатково перевіряють ID адміністратора.

## Важливо щодо Google Sheets

Формула в \`Авто-баланс🤑!B2\` має враховувати нарахування з аркуша \`Нарахування💰\` та винагороди зі стовпця H аркуша \`Ставки🎯\`. Очікувана формула:

\`=SUMIF('Нарахування💰'!B:B;A2;'Нарахування💰'!I:I)+SUMIF('Ставки🎯'!B:B;A2;'Ставки🎯'!H:H)\`

Перевірте формулу та протягніть її вниз для всіх гравців. Формулу поточного балансу \`D2=B2-C2\` залишити без змін. Не записуйте нагороди паралельно в аркуш «Нарахування💰».

## Тестування

Встановіть залежності з \`requirements.txt\`, потім запустіть:

\`\`\`bash
python -m unittest discover -s tests -v
\`\`\`

Перед production-публікацією протестуйте авторизацію Telegram Mini App, інтеграцію з тестовою копією Google Sheets, таймери, перезапуск процесу й повторне підтвердження результатів. Локальна синхронізація Google Sheets не є транзакційною, тому при помилці запису перевіряйте рядки ставок і стани до повторної дії.
